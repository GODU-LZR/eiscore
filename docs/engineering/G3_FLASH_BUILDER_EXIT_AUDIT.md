# G3 FlashBuilder 阶段退出审计

## 结论

`FlashBuilder.vue` 的纯策略拆分阶段通过退出审计。页面从 G3 起点的 4,264 行降至 3,741 行，减少 523 行（12.3%）；草稿来源、Shell 会话、Markdown 安全渲染和预览策略已进入 4 个无 Vue、Element Plus、网络、浏览器、Storage 或隐式时间依赖的纯模块，共 39 个具名导出。

该结论关闭的是 FlashBuilder 当前纯策略子目标，不等于把页面降到普通组件规模。页面仍有 366 行模板、2,057 行组合脚本和 1,315 行局部样式；Flash 工具、IDE 探测、WebSocket/Cline、iframe、上传、发布和视觉组件的后续拆分必须由真实交互回归或明确复用收益驱动。G3 转向当前更大的未退出高风险巨页。

| 边界 | 迁出职责 |
| --- | --- |

## 页面保留职责

- 维护 Vue Ref/Computed/Watch、当前应用、模式、会话、消息、附件、预览与发布状态。
- 通过既有 Axios Flash Tool 入口、IDE Fetch 探针和 WebSocket/Cline 通道保持原协议、认证和时序。
- 装配安全会话缓存与远端 `source_code.flash` 同步，保留 12/120/12 上限和本地/远端调度。
- 执行 iframe/DOMParser、编辑器全屏、文件读取、上传、流式打字、自动重试、预览刷新、发布、Router、消息和确认。
- 保留 366 行现有模板和 1,315 行 Scoped CSS，避免无浏览器证据的交互、拖拽、响应式布局和视觉漂移。

这些职责是当前 FlashBuilder 的组合、协议和展示边界。继续拆分需要登录态 IDE、真实 Agent/Cline、附件、预览与发布链路的浏览器证据；只按物理行数搬运会扩大连接生命周期、计时器、DOM 引用和样式作用域风险。

## 非阻断项

- 页面仍显著高于 800 行审查阈值，逐文件与总债务棘轮继续禁止增长。
- 1 个 Axios Agent 请求、1 个 IDE Fetch 与 1 个 WebSocket 是专用协议边界；新增协议不得继续内联，后续应按独立客户端切片治理。
- 2,057 行组合脚本和 1,315 行样式尚未拆 Composable/视觉组件；本阶段没有登录态浏览器、IDE/Cline 或截图基线，因此接受保留。
- Markdown 对带括号的危险链接退化后会保留尾随右括号，源码兜底 Snapshot 的标题沿用既有未转义应用名；为避免把产品修复混入重构，本阶段按现状锁定，后续应作为独立安全/显示缺陷评估。
- 未调用 Agent/Cline、数据库、Flash Tool、IDE 或企业环境；上传、流式会话、草稿同步、预览和发布仍需隔离环境演练。
- 当前验证机为 Node 26.1.0 / npm 11.13.0；发布证据仍要求 Node 20.19.0 / npm 10.8.2。

## 回退与下一目标

四个抽取切片均为独立提交，不包含数据、接口或部署变更，可按职责单独回退；回退会恢复页面内联实现并失去对应专项门禁。退出审计本身只增加离线门禁和文档。

G3 下一目标为 4,003 行的 `eiscore-base/src/layout/index.vue`。它是当前最大的未退出 Vue 巨页，直接承载标签、菜单、主题、企业配置、身份权限和窗口事件；应先建立职责库存和行为特征测试，再选择无视觉变化的纯策略边界。
