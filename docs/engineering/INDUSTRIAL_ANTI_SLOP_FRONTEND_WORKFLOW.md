# 工业独立站去模板化前端工作流

## 目的

这份规则用于伦度机电及同类工业企业独立站、品牌登录页和产品展示页。目标是让页面承担真实的产品沟通和采购入口，而不是展示一组泛化的 AI 文案、渐变背景和解释性卡片。

## 事实和品牌资产

先读取企业配置、现有路由、图片清单和官网资料，再决定页面结构。企业名称、产品系列、应用场景、认证、客户、产量、订单量和性能参数都必须有来源；没有来源就不写成事实。

伦度 Logo 的唯一前端资源为：

`eiscore-base/public/enterprise-assets/site/lundu-logo.png`

企业配置通过 `branding.logoUrl` 引用 `/enterprise-assets/site/lundu-logo.png`。页面应直接复用该配置，不在组件内写死另一个 Logo，也不使用生成图替换官方标识。

## 内容组织

首屏先回答四件事：伦度是谁、主要做什么产品、产品服务哪些工况、用户下一步可以做什么。产品区应使用真实的产品名称、系列、用途、选型信息和交付边界；制造区应描述可核验的工艺或服务，不用空泛的“赋能、生态、闭环、数字化运营”等词填充版面。

企业概况要像正式公司介绍，使用地点、主营方向、研发制造销售服务范围和资料中可确认的经营信息。不要把联网检索结果、内部实现说明、AI 生成提示或编辑注释直接暴露在页面上。

## 视觉规则

- 使用清楚的网格、留白、边界和品牌色，控制圆角、阴影和装饰数量。
- 避免大面积通用渐变、玻璃拟态、漂浮光球、重复编号卡片、超大口号和嵌套卡片。
- 版块必须服务于产品、应用、制造、质量或联系动作；没有信息价值的装饰删除。
- 登录页仍然是独立站入口：保留企业登录动作，但让产品、场景和品牌先于后台解释出现。

## 图片和响应式布局

产品图要把主体放在画面中央，四周保留可用留白。产品卡、横幅和移动端使用独立的比例容器，产品主体使用 `object-fit: contain` 和居中定位；场景图只有在主体不会被裁切时才使用 `cover`。生成或裁切素材时，先按插槽比例准备安全区，再放入网页，避免黑边、截断和强行拉伸。

移动端按钮、标签和关键标题尽量保持单行。使用 `white-space: nowrap`、合适的最小宽度和断点字号，并对最长真实文案测试。所有固定尺寸的图片、画布、控制条和产品网格都要有稳定的 `aspect-ratio`、`minmax` 或容器约束，防止加载内容时布局跳动。

## BOM 三维展示

桌面端可以保留旋转和缩放。移动端应关闭旋转和缩放，把 canvas 的内联 `touchAction` 设为 `pan-y`，避免 Three.js 控件拦截页面下滑。动画按真实装配关系组织：内部零件先到位，左右半圆筒沿水平方向合并，合体后不留可见缝隙；线圈、转子、密封件和端盖保持明确间隙，不用穿模来表达装配完成。

## 每次修改后的验收

使用 Playwright 或仓库现有浏览器工具，在同一路由和同一状态下检查：

| 视口 | 重点 |
| --- | --- |
| 390 x 844 | 窄屏单行控制、图片完整、纵向滚动 |
| 414 x 896 | 移动端留白、产品卡比例、按钮宽度 |
| 768 x 1024 | 平板断点、两列到一列的过渡 |
| 1440 x 900 | 桌面首屏层级、产品网格和导航 |

每次都确认 Logo、图片和字体没有 404；产品主体没有裁切或黑边；文字、按钮和导航没有重叠；移动端 `document.body.scrollWidth <= window.innerWidth`；手指在 BOM 画布上滑动时页面仍能纵向滚动；产品目录写的是具体系列而不是宣传口号。

推荐的最小断言：

```js
await expect(page.locator('img[src*="lundu-logo"]')).toBeVisible();
expect(await page.evaluate(() => document.body.scrollWidth <= window.innerWidth)).toBe(true);
```

断言只负责发现结构问题，最终仍要看四个视口截图，尤其要检查图片主体是否完整和 BOM 装配是否穿模。
