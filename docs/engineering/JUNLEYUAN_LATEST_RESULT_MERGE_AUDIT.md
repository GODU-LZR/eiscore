## 行为与回退

- 配置卡优先使用 V2，加载失败时浏览器继续使用 V1 图层。
- 球杆木材与镶嵌优先加载 V3；失败时保留程序化木纹或原实体色。
- 每次设计重建生成新的令牌，迟到的旧纹理立即释放，不得写回新模型。
- 重建和卸载会释放已加载纹理、材质、几何体与木纹缓存。
- Visual BOM 同时携带来源资产、V2 卡片、V3 纹理及回退路径，后续服务端可审计但不得将候选状态解释为生产批准。
