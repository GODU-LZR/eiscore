> 准备日期：2026-09-02

## 需要决定什么

G4 的目标不是复制三套源码，而是证明同一版本的 EISCore 核心制品能够通过受校验、可版本化、可审计的企业包分别服务伦度机电、君乐缘和经纬网厂。开始实现前，需要先确定配置边界、部署拓扑和三家企业的真实启用范围。

## 必须保持的既有不变量

1. 不修改 `github-eiscore` 原仓库、客户生产环境或现有客户数据。
2. 三家企业不得产生三套源码分支；客户差异只能进入配置、内容、素材或初始化数据包。
3. `system_configs.app_settings` 只保存内部系统偏好，不重新接管企业公开资料。
4. 已发布企业档案只由企业站点运营编辑和发布；部署配置只能承担启动身份、内部产品外观、服务端点、模块和功能开关。
5. 客户 seed 与结构迁移分离；所有待复核事实、素材来源和授权状态必须显式记录。
6. 核心制品必须可追溯到同一提交，切换企业包不能改变核心 JS/CSS 哈希。

## 推荐决策

### D1：首批保持三套隔离的单租户部署

建议伦度机电、君乐缘和经纬网厂各自使用独立数据库与运行环境，但运行相同核心制品版本。当前 `site_key=primary` 契约、鉴权和上线手册都支持该方案；此时强行改成共享数据库多租户会扩大数据隔离、RLS、缓存、域名解析和恢复范围，不属于首批落地的必要条件。

### D2：企业包拆成运行配置与企业数据两层

- 运行配置：企业 ID、内部显示名、内部产品标题/主题、端点、模块开关和功能开关。
- 企业数据：已发布企业档案、页面、产品、方案、案例、FAQ、SEO 和经授权素材，以及数据包版本与校验和。

核心前端/后端镜像属于同一制品；三家企业数据和素材可以不同，但必须作为独立版本化输入追踪，不能烘焙成三份不同源码制品。

### D3：收紧 v1 登录品牌兼容面

当前 v1 Schema 的 `branding.login` 仍允许 slogan、介绍、导航、指标、业务链、能力、轮播和领导等大量历史字段。它们作为迁移期兼容读取可以暂时保留，但不得复制进三家新配置包，否则会重新形成企业站点运营之外的第二份公开资料。

建议 G4 首个实现切片先形成兼容升级决策：新企业包只允许启动所需的最小登录兜底；已发布档案存在时，公开企业内容始终以 `company_site.site_config` 为准。字段废弃、版本升级和回退方式需要单独 ADR 与契约测试，不能静默删除现有 v1 字段。

### D4：以同制品证据定义“配置化完成”

G4 验收时应先生成一次核心制品并记录哈希，再分别挂载三家企业包运行。验收比较的是相同核心制品哈希、不同企业包校验和，而不是分别执行三次客户化构建后只比较版本号。

- 品牌/Logo、域名、市场语言、产品公开范围、公开文案、联系方式、合规与素材授权仍未开始填写。

- 待补清单把范围、产品、BOM、工艺和质量资料列为 P0，把独立站品牌、域名和公开产品范围列为待补项；这些缺口关闭前不能形成上线验收证据。

因此，伦度工作簿可以作为 G4 的需求追溯输入，但不能直接转换为生产配置或初始化数据。工作簿中的内部主体字段不应复制到公开站点或一般工程文档。

## 建议的 G4 实现切片

只有用户确认进入 G4 后才执行：

1. **G4.0 配置边界**：ADR、企业包目录规范、Manifest、Schema 版本与兼容/回退策略。
2. **G4.1 校验与打包**：离线校验器、校验和、禁止秘密值、禁止未知字段、资产引用和模块依赖检查。
3. **G4.2 三家迁移**：先迁移证据较完整的君乐缘和经纬网厂；伦度机电以现有采集表追踪缺口，只在对应字段获得确认后建立，不填虚构占位事实。
4. **G4.3 同制品运行**：一次构建、三套隔离环境、三套配置挂载、核心制品哈希一致性证明。
5. **G4.4 企业功能验收**：逐企业验证登录、菜单、路由、模块关闭、权限、企业站发布生命周期和实际启用业务链。
6. **G4 退出审计**：记录通过项、未验证项、升级/回退、数据恢复点和是否允许进入 G5。

每个切片独立提交并运行既有 G1～G3.5 门禁；不得把“配置文件能够通过 JSON Schema”当成三家企业功能验收完成。

## 需要用户确认的信息

进入 G4 前，至少需要确认：

1. 是否接受“三家独立单租户部署、相同核心制品”的首批拓扑。
2. 每家企业的法定名称、对外品牌、内部系统名称、正式域名及确认人。
3. 每家企业实际启用的模块、功能、角色和至少一条上线必需业务链。
4. 是否确认现有《伦度采集表格》为需求追溯起点，并继续补齐其中的 P0 范围、产品、BOM、工艺和质量资料。
5. 君乐缘与经纬现有图片、Logo、商标、文案和研究结论中哪些已经获得生产使用确认。
6. 是否把旧数据迁移纳入 G4，还是先用受控样本完成同制品验证后再进入数据迁移。
