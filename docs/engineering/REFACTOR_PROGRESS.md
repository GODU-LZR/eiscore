- 不整体重写；先用特征测试保护行为，再按业务切片渐进迁移。

- 每个切片必须形成小提交，并记录实际验证、未验证项和剩余风险。

## 当前切片

- 状态：G2 进行中；Auth/Session 与会话 Storage 子目标已完成，下一步转向 Request/错误边界。

## 已知非阻断风险

- 当前 npm 对 `esbuild`、`@parcel/watcher`、`vue-demi`、`sharp` 等第三方安装脚本给出未显式批准告警；现有 11 个前端构建仍全部成功。
- 多个前端共享构建配置报告 `vendor-misc` 与 `vue-runtime` 循环分包，应在公共构建边界单独治理。
- `eiscore-apps` 的 BPMN 主块约 1.57 MB，存在首屏加载与缓存更新成本。
- 部分依赖出现弃用或 Rollup/Sass 兼容告警，需要纳入依赖升级策略，不能与业务重构混合处理。
- 生产部署脚本仍包含 `npm install` 和全局 PM2 安装，属于 G5 可重复部署治理范围。
- Auth/Session 与两个兼容会话 Key 的产品消费已完全收敛；重复 Request、Realtime、错误映射及普通偏好/业务缓存仍属于 G2 后续迁移范围。
- 平台 HTTP 已覆盖系统配置首条真实链路；基座全局 `fetch` 401 兜底、Axios 拦截器及其他模块局部客户端仍需在迁移具备充分覆盖后收敛。
- 销售→采购/仓储试点已迁入平台导航服务；其他业务页面仍有直接跳转和具体路径，须按真实业务链逐步迁移。
- 当前兼容配置仍引用既有第三方 HTTPS 图片地址；建立三家企业配置包时应把获授权素材镜像到企业自有静态资源域名并验证可用性。
