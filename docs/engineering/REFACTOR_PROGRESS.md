## 不可变约束

- 原始仓库保持只读；重构只在独立仓库的 `codex/systematic-refactor` 分支进行。
- 起始检查点为 `e5d0b92`，包含全部已确认的最新业务成果和前三个工程化切片。
- 不向任何远端推送，除非用户后续明确授权。
- 不整体重写；先用特征测试保护行为，再按业务切片渐进迁移。
- 不运行可能写入真实环境的 `:remote` 测试，除非用户明确授权目标环境和数据写入。
- 每个切片必须形成小提交，并记录实际验证、未验证项和剩余风险。

## 当前切片

- 状态：G2 进行中，会话失效清理已从 Auth 工具扩展到首批真实消费者。
- 结果：基座全局 `fetch` 401、移动路由守卫及仓库/库存/考勤/盘点 4 个 API 不再直接操作 `auth_token`、`user_info` 或自行 Base64 解码，统一经过桌面/移动 Auth 适配器。移动端上述链路的直接会话调用已清零，仓库范围剩余量缩小为基座 9 个文件、30 处。
- 兼容边界：基座仍只对同源 `/api` 401 清会话并跳 `/login`；移动 API 仍跳 `/mobile/login` 并抛出“登录已过期”；移动路由继续携带原 `redirect` 查询参数，且为避免结构重构改变登录政策，仍只在 JWT 明确包含已到期 `exp` 时拒绝。没有改变 HTTP 请求、接口或部署拓扑。
- 验证：完整质量门禁通过，覆盖 74 个 Node 脚本、14 个 CI 包、会话失效迁移契约、1133 个文本秘密扫描、16 个变更代码文件 lint、23 个 Shell 与生产 Compose；移动登录反馈与 PDA 回归通过；基座与移动端生产构建分别转换 5863、1465 个模块。

## 已知非阻断风险

- 当前 npm 对 `esbuild`、`@parcel/watcher`、`vue-demi`、`sharp` 等第三方安装脚本给出未显式批准告警；现有 11 个前端构建仍全部成功。
- 多个前端共享构建配置报告 `vendor-misc` 与 `vue-runtime` 循环分包，应在公共构建边界单独治理。
- `eiscore-apps` 的 BPMN 主块约 1.57 MB，存在首屏加载与缓存更新成本。
- 部分依赖出现弃用或 Rollup/Sass 兼容告警，需要纳入依赖升级策略，不能与业务重构混合处理。
- 生产部署脚本仍包含 `npm install` 和全局 PM2 安装，属于 G5 可重复部署治理范围。
- 10 个 Auth 工具及首批失效链已收敛到平台会话；基座页面、Store、微前端状态桥和局部 API 仍有 30 处直接会话存储调用，重复 Request、Realtime 工具也属于 G2 后续迁移范围。
- 平台 HTTP 已覆盖系统配置首条真实链路；基座全局 `fetch` 401 兜底、Axios 拦截器及其他模块局部客户端仍需在迁移具备充分覆盖后收敛。
- 销售→采购/仓储试点已迁入平台导航服务；其他业务页面仍有直接跳转和具体路径，须按真实业务链逐步迁移。
- 当前兼容配置仍引用既有第三方 HTTPS 图片地址；建立三家企业配置包时应把获授权素材镜像到企业自有静态资源域名并验证可用性。
