# G3 Realtime 后端退出审计

## 结论

Realtime 后端模块化子目标通过退出审计。`realtime/index.js` 已从 G3 起点的 7,386 行降至 770 个物理行，只保留配置读取、能力装配、通用 HTTP/WebSocket/JWT 辅助、授权适配和进程生命周期；已盘点的领域规则、数据库访问、文件系统操作、外部 AI 调用、子进程和具体路由分发均位于独立模块。

本结论只关闭 Realtime 后端子目标，不代表 G3 全部完成。G3 下一项是建立巨型 Vue 页面的量化库存、职责分类和渐进拆分门禁。

## 接受门槛

| 门槛 | 结果 | 持续证据 |
| --- | --- | --- |
| 组合根规模不超过 800 行 | 通过：770 个物理行 | `realtime-composition-root-regression.mjs` |
| 本地模块依赖显式且无隐式增长 | 通过：28 个本地边界 | 精确依赖清单门禁 |
| 组合根辅助函数只属于配置、传输、鉴权、清洗和生命周期 | 通过：26 个具名辅助函数 | 精确职责清单门禁 |
| 不重新内联数据库、文件、子进程或领域表细节 | 通过 | 禁止依赖与领域标记门禁 |
| HTTP/WebSocket 入口和关闭协议唯一 | 通过 | 单 Server、单 WS 装配、双信号与 `allSettled` 契约 |
| 离线完整验证 | 通过 | `test:quality` 与 `test:unit` |

## 已退出组合根的职责

| 边界 | 迁出职责 |
| --- | --- |
| HTTP / WebSocket | 41 条 HTTP Manifest、9 类 WS 分发、Twin/AI/Flash 处理器 |
| 数据与通知 | PostgreSQL LISTEN/重连/Workflow、用户态 PostgREST、动态表恢复 |
| AI | 配置缓存、上游重试/流、OCR、输出守卫、Agent 策略、本体与十二域快照 |
| Agent | 角色/项目/写策略/审计、任务、FileWatcher、工具、终端、连接清理 |
| Flash | 43 项注册表、确认/幂等策略、语义执行矩阵、Cline 配置/运行时/生命周期 |
| 文件 | 草稿 Preview/Scoped 同步、指纹、附件校验/落盘/预览/审计 |

## 组合根保留职责

- 读取进程环境并把配置注入服务。
- 创建 HTTP Server、WebSocket Server、Workers、Notifier 和各领域服务。
- 提供通用 JSON/SSE/WS 传输、JWT 解析和轻量参数清洗。
- 把通用鉴权结果适配给 AI、Agent、Twin 和文档入口。
- 启动、信号处理和并发关闭进程资源。

这些职责跨越多个模块且属于可执行程序的组合边界，继续拆分不会直接降低业务变更风险，因此本阶段接受保留。

## 非阻断项

- Realtime 仍是单进程模块化单体；本阶段没有改变端口、部署拓扑或数据库。
- 环境配置除 Cline 子域外仍在组合根集中读取；已由精确职责和规模门禁限制增长。
- `index.js` 启动时有进程副作用，专项测试通过独立服务和静态组合契约验证，未启动真实服务。
- 当前验证机为 Node 26.1.0 / npm 11.13.0；发布证据仍要求锁定的 Node 20.19.0 / npm 10.8.2。

## 回退

所有迁移均为可独立回退的小提交，没有数据迁移。回退任一领域切片只恢复对应内联实现；会失去该模块的专项契约和组合根门禁，但不要求数据库回滚。
