# G3 EquipmentHome 阶段退出审计

## 结论

EquipmentHome.vue 的当前纯策略拆分阶段通过退出审计。页面锁定为 1,641 行，模板/组合脚本/样式分别为 401 / 260 / 978 行；6 个无 Vue、Element Plus、网络、浏览器、Storage 或隐式时间依赖的纯策略模块共导出 43 项规则。

该结论关闭的是本页当前纯策略子目标，不代表驾驶舱模板和样式已完成组件化。页面继续持有六路设备查询、Realtime 订阅、Router、时钟/刷新 Timer、Fullscreen、加载和生命周期编排；这些边界由组合门禁锁定，后续拆分必须以真实设备状态、告警与截图证据驱动。

## 已退出职责

驾驶舱展示投影、KPI/风险摘要、日期趋势与告警、六表数据归一化、六路加载查询及壳层投影已迁入纯模块。策略显式接收参考时间和输入数据，页面继续负责响应式状态和副作用执行。

## 保留边界

- 维护六类数据集、加载/错误状态、Realtime 事件计数、Computed/Watch 与展示组合。
- 通过既有 Request 适配器执行六路查询并保留顺序、limit、刷新与失败回退。
- 保留 Router、Realtime subscribe、1 秒时钟、30 秒刷新、防抖清理、Fullscreen 与 DOM 生命周期。
- 保留 401 行模板和 978 行 Scoped CSS，避免无真实设备、告警和多分辨率基线的机械迁移造成视觉漂移。

## 非阻断项与回退

页面仍高于 800 行阈值，复杂度门禁只允许下降；当前仅验证离线策略与组合门禁，未访问数据库、远程 API 或企业环境。各抽取切片不含数据迁移，可按职责回退并同步移除对应专项门禁。
