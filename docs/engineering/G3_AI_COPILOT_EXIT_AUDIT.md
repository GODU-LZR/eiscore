# G3 AiCopilot 阶段退出审计

## 结论

`AiCopilot.vue` 的纯策略拆分阶段通过退出审计。页面从 G3 起点的 4,393 行降至 3,522 行，减少 871 行（19.8%）；Workflow 元数据、智能 BI 行动、通用导入、消息结构块、模板库、报告和图表配置已进入 7 个无 Vue、Element Plus、HTTP、浏览器或 Storage 依赖的纯模块，共 77 个具名导出。

该结论关闭的是 AiCopilot 当前纯策略子目标，不等于把页面降到普通组件规模。页面仍是 509 行模板、1,765 行组合脚本和 1,245 行局部样式；AI Bridge、Markdown/DOM、图表实例、平台请求或视觉组件的后续拆分必须由真实交互回归或明确复用收益驱动。G3 转向当前更大的高风险巨页。

| 门槛 | 结果 | 持续证据 |

| 不重新引入平台旁路 | 通过：无直接 Fetch、Axios、Storage、EventSource、WebSocket、XMLHttpRequest 或 `window.location` 导航 | 禁止访问门禁 |

## 页面保留职责

- 维护 Vue Ref/Computed/Watch、会话、历史、Lightbox、保存/导入/Workflow/行动状态。
- 调用 AI Bridge 与宿主客户端，执行 8 个系统配置、物料、动态导入和 Workflow/行动读写点及其顺序。
- 装配 MarkdownIt、HTML/SVG Sanitizer、DOM 报告分节、Mermaid/ECharts 动态加载、实例缩放和卸载。
- 执行剪贴板、打印窗口、CustomEvent、Router、消息、确认及三类窗口事件生命周期。
- 保留 509 行现有模板和 1,245 行 Scoped SCSS，避免无浏览器证据的交互与视觉漂移。

这些职责是当前 AI Copilot 页面的组合和展示边界。继续拆分它们需要真实流式对话、图表、Workflow、物料导入和打印链路的浏览器证据；只按物理行数拆分会扩大状态时序、DOM 引用和样式作用域风险。

## 非阻断项

- 页面仍显著高于 800 行审查阈值，逐文件与总债务棘轮继续禁止增长。
- 8 个宿主 HTTP 调用仍位于组合页；新增协议必须进入小型 Service/Adapter，后续可按模板、物料或 Workflow API 族独立迁移。
- Markdown/图表/报告 DOM 和 1,245 行样式尚未拆视觉组件；本阶段没有登录态浏览器、真实流式 AI 与截图基线，因此接受保留。
- 标题规范化的既有顺序会把“第3部分”处理为“部分”，宽松 JSON 在行尾注释前的尾逗号也可能保留；为避免把产品修复混入重构，本阶段按现状锁定，后续应作为独立缺陷处理。
- 未调用 AI、数据库、PostgREST、Workflow 服务或企业环境；模板保存、物料导入、行动闭环、图表、报告和流式对话仍需隔离环境演练。
- 当前验证机为 Node 26.1.0 / npm 11.13.0；发布证据仍要求 Node 20.19.0 / npm 10.8.2。
