- 保留全部既有业务成果和对外行为。

## 3. 架构变化

已建立无业务依赖的 `@eiscore/platform` 包，企业配置 v1 通过同一入口完成校验、规范化、递归冻结和加载；品牌、端点、10 个模块与功能开关具备版本化契约。后续继续汇总 HTTP/Auth/Storage、核心模块和数据迁移变化。

基座已在 Vue 挂载前加载企业配置，正式构建运行时缺失配置会失败关闭；qiankun 保持 9 个原有子应用默认启用，并支持按企业模块开关过滤注册和传递只读配置。

模块开关已统一控制基座菜单、预热、历史标签、跨窗口标签、直达路由和移动设备跳转，禁用模块不会被基座注册或恢复入口。

已按真实回退入口与业务链建立 10 个企业模块的无环依赖契约，部署配置不能启用缺少必需下游模块的组合；应用中心的可选遗留跳转不反向强制全部模块启用。

已建立不依赖 Vue 的平台导航服务：仅接受安全的同源绝对路径，在跳转前统一执行企业模块开关检查，并分别适配 qiankun 宿主标签导航与子应用独立运行。销售到采购需求、出货申请和销售出库三条真实入口已作为首个迁移试点，原路径及查询参数保持不变，禁用目标模块时不再误跳转。

企业登录品牌已从桌面 Store、桌面登录、系统设置和移动登录四处重复实现迁入部署配置。平台适配器统一企业名称、Logo、主题、登录文案、指标、业务链、能力、轮播图、管理团队及移动差异字段；管理员保存在 `app_settings` 的运行期设置继续作为覆盖层。当前登录页成果完整保存在兼容配置数据中，产品源码不再包含客户名称或客户素材域名。移动端也在 Vue 挂载前加载企业配置，正式制品配置错误时失败关闭。

已建立产品级平台 HTTP 契约：请求地址只能由企业端点配置与安全资源路径组合，认证信息通过适配器注入，默认超时、401 通知和错误分类保持一致，错误消息不会包含查询参数、Token、请求体或服务端响应。桌面系统配置读写和移动登录配置读取已完成首个真实链路迁移；平台层不自动重试写请求。边界决策见 ADR-0003。

已建立平台 Auth/Session 与安全存储契约：继续读取纯文本和 JSON 两种存量 Token，统一 UTF-8 Base64URL JWT 解码、严格过期判断、8192 字符上限和双 Key 清理；Storage 禁用、配额不足或损坏 JSON 均失败关闭且不泄露 Key/Value。基座、移动端及 8 个微应用共 10 份 Auth 工具均已保留原导出和登录路径迁入薄适配器，平台层不承担导航或 JWT 签名校验。边界决策见 ADR-0004。

已建立无 Vue 与 Storage 依赖的平台权限服务，基座及 8 个微应用共 9 个权限工具改为薄适配器。通用权限集合、`app_role`/`appRole`/`role`、`super_admin`、销售/采购模块授权与经理角色特例、读错降级差异及原导出保持；平台判断只负责前端可见性，不替代服务端授权。G2 退出审计同时确认企业配置、Auth/Session、普通受保护 HTTP、基础设施错误边界和前端权限判断已具备退出证据，并量化剩余非会话 Storage 16 个文件/58 处、全页导航 20 个文件/24 处及 8 份共享 Grid 副本。边界决策见 ADR-0005。

智能收单记录、决策驾驶舱、移动 PDA、生产下推 3 条和采购入库共 5 个消费者/7 处跨模块整页跳转已进入平台导航。动态业务记录、既有路径与查询参数、决策标签标题、业务单据写入及提示时序保持；目标模块禁用时统一反馈，qiankun 通过宿主标签打开，独立运行继续整页导航。直接整页跳转库存由 20 个文件/24 处降为 15 个文件/17 处，余量限于认证/登录、移动与桌面入口切换及基座受控外部路由；动态 Vue Router 仍待复审。

材料端与移动端两份盘点缓存已收敛为一个共享领域服务，继续使用原 3 个 Key、版本 1、时间戳、仓库/Meta、冷库模式和待同步队列协议，两个应用的 9 个公开函数保持。共享服务通过平台安全存储捕获浏览器禁用、配额和损坏 JSON，错误队列类型降级为空数组且不记录 Key/Value；18 处重复 Storage 调用收敛为共享边界 1 处，总库存由 16 个文件/58 处降至 15 个文件/41 处。边界决策见 ADR-0006。

## 5. 升级、回退与运行治理

导航切片没有接口、数据或部署变更；可通过回退对应单提交恢复旧的销售、5 个明确消费者或 AppRuntime 自建导航。品牌切片不改变数据库结构或接口，兼容配置随基座静态制品发布，并可由企业只读挂载覆盖；回退对应单提交即可恢复原硬编码默认值。HTTP 切片保持原 PostgREST 路径和 profile，可回退单提交恢复直接请求；移动 wrapper/PDA、AI 工作流、生产驾驶舱与 EISGrid RPC 切片也没有数据库、接口或部署变化，单提交回退即可恢复局部请求器或页面请求。直接请求门禁、全局劫持退役、共享 Geo、智能收单、业务快照、Twin JSON、Flash JSON 及 Agent SSE 边界均不改接口、数据或部署，单提交回退可恢复旧兜底或局部实现；SSE 回退后仅失去新增的卸载/模式切换取消能力。质量/设备 Axios 迁移同样不改调用方或接口，且没有自动重试风险。Auth/Session、8 个微应用及失效链迁移均保留原 Key、Token 格式、导出和登录路径，无数据迁移，可分别回退对应小提交恢复局部实现。权限平台化同样不涉及数据库、接口或部署变化，单提交回退即可恢复 9 份局部策略实现；回退后只失去统一策略边界与库存门禁。已迁移的各 Storage 族均保留原 Key 和格式，无数据迁移；单提交回退会恢复局部实现，但重新暴露 Storage 异常。后续继续汇总升级路径、兼容策略、回退演练和可观测性能力。
