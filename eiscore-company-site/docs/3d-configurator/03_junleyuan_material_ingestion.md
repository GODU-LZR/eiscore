# 君乐缘素材接入记录

日期：2026-08-13

## 本轮来源

本轮读取了工作区中的以下企业资料：

- `君乐缘素材.xlsx`：1 个工作表，32 行，68 个唯一嵌入图片引用，原始图片约 603 MB。
- `君乐缘.docx`：君乐缘提供的木料名称和部分长度信息。
- `君乐缘项目部署实施参数与网站素材采集表.md`：素材授权、隐私检查和公开范围仍有多项待确认。
- `君乐缘台球工厂企业介绍.pdf`：作为企业资料候选来源，未自动拆分或发布其中的图片。

工作簿中的图片分类包括产品展示、冲杆、手工杆展示、黑檀、孔雀木、紫心木、枫木、可可木、海南黄花梨、花梨木、黄檀、镶嵌/高插以及烘干房等现场图片。

## 已接入原型的候选预览

从工作簿原图生成了 14 个轻量 JPEG 预览，存放在 `public/assets/junleyuan-materials/`。它们只用于 EISCore 内部 Cue Builder 原型的材质卡和 Three.js 预览：

- 木材：紫心木、黑檀、枫木、可可木、孔雀木、海南黄花梨、巴西花梨木、微凹黄檀、黄金樟。
- 镶嵌/高插：科技木郁金香、蛇纹木八插、黑白檀高插、龙鳞插片、郁金香高插。

每个预览在 `assets/manifests/asset_manifest.json` 中记录了来源工作簿单元格、原始媒体名、提交到构建产物的预览 hash、版本和候选状态。

## 使用边界

当前资产统一为：

- `status=candidate`
- `approved=false`
- `commercial_use=false`
- `license_id=supplier_authorization_pending`

因此它们不能作为公开独立站生产资源、正式 PBR、正式 SKU 图片或生产 BOM 依据。它们也没有被加入 `enterprise-site/` 的公开站点资源。

本轮没有把约 603 MB 的原始工作簿复制进 Git。原始资料仍保留在项目工作区，提交到子应用的只是用于内部交互验证的压缩预览。

## 下一闸门

在任何公开上线或正式报价前，工厂/企业负责人需要确认：

1. 每张图片的拍摄/提供者和商业网站展示授权。
2. 木材准确物种、产地、供应商、可出口国家和 CITES/Lacey 等合规信息。
3. 真实长度、截面、公差、含水率、可加工区域和适用槽位。
4. 预览图与实际木样的色差、灯光条件和是否需要重新拍摄标准色卡。
5. 价格、库存、MOQ、交期和制造 BOM 映射。
6. 原始图、裁切图、PBR 贴图和后续 GLB 的授权凭证与 SHA-256。

确认后再将候选资产升级为版本化正式资产，并接入服务端 `validate -> quote -> bom` 闸门。
